# ZA Server VPS Configuration

Complete VPS setup for South African server with DigitalOcean or Oracle Cloud.

## Specifications
- **CPU**: 8 cores
- **RAM**: 6GB
- **Storage**: 1TB
- **Bandwidth**: Unlimited
- **OS**: Ubuntu 22.04 LTS
- **Setup**: Production-ready web server

## Quick Start

### Option 1: DigitalOcean
```bash
bash scripts/digitalocean-setup.sh
```

### Option 2: Oracle Cloud
```bash
bash scripts/oracle-setup.sh
```

## Contents

- `terraform/` - Infrastructure as Code (IaC)
- `scripts/` - Automated setup scripts
- `config/` - Server configurations
- `monitoring/` - Health check and monitoring setup
- `backup/` - Backup scripts
